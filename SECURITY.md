# Política de Segurança — Flowrish

Levamos a segurança da comunidade e a privacidade dos dados dos leitores muito a sério.

## Versões Suportadas
Apenas a versão estável mais recente publicada na branch principal (`main`) recebe atualizações e correções de segurança ativas.

| Versão | Suportada |
|---|---|
| 1.2.x | :white_check_mark: Sim |
| < 1.2.0 | :x: Não |

## Relatando Vulnerabilidades
Se você identificou uma vulnerabilidade de segurança (ex: falhas de autenticação, vazamento de credenciais, injeção de dados):
- **NÃO** abra uma Issue pública no repositório.
- Utilize a aba **Security > Report a vulnerability** no GitHub ou envie uma notificação privada para os mantenedores.
- Informações úteis para incluir:
  - Descrição da vulnerabilidade e impacto potencial.
  - Passos reproduzíveis ou prova de conceito.
  - Sugestão de correção, se houver.

Nos comprometemos a responder em até 7 dias úteis com o plano de remediação.
